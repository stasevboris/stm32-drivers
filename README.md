# STM32F401RE: драйверы на C

Драйверы на регистрах CMSIS для микроконтроллера STM32F401RE:

| Модуль | Назначение |
|--------|------------|
| `clock.c/h` | настройка тактирования |
| `gpio.c/h` | порты ввода-вывода |
| `timer.c/h` | аппаратные таймеры |
| `delay.c/h` | задержки |
| `lcd1602.c/h` | символьный дисплей LCD1602 по I²C |

`STM32F401RE_I2C.hex` — собранная прошивка, `*.pdsprj` — схемы для симуляции в Proteus.
